Inter Math workbench

SpecimensSymbolsReviewOverlayOpenType

Pages to look at the font while it is drawn, apart from the app.

  • Specimens: school math in KaTeX's Computer Modern and in Inter Math, any LaTeX to try in both.
  • Symbols: every example of KaTeX's documentation (Supported Functions, Support Table) in both fonts, with the glyphs of Inter each of Inter Math's is drawn from, and what still falls back to KaTeX.
  • Package: the npm package as pnpm dist builds it (its stylesheet, fonts and KaTeX).
  • OpenType: the OpenType math font in the browser's MathML (its MATH table), beside Inter Math in KaTeX.

pnpm workbench serves them (after font:build); node workbench/katex-docs.mjs extracts KaTeX's documentation again.
