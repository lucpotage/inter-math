Inter Math examples

The same formulas set by each engine Inter Math works with, from the npm package as pnpm dist builds it (dist/npm/): run pnpm dist, then pnpm examples and open http://127.0.0.1:3153/examples/.

  • KaTeX: the package's KaTeX, laid out with Inter Math's metrics at any weight.
  • MathML: the browser's own layout, from the OpenType font's MATH table.
  • Temml: LaTeX written as MathML, laid out by the browser the same way.
  • TeXZilla: the same, another LaTeX to MathML converter.
  • MathJax: MathJax 4 with Inter Math as its font (SVG output).
